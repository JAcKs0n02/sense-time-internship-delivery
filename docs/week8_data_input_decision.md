## 为什么这样选择

9月11日冻结说明明确采用共同KEEP原文路线，未把2165条待核对修订稿投入训练。选取1664条共同KEEP后排除候选4449，得到1663条；其余3245条保留排除账本，其中最新REVISE 2203、HOLD 284、DROP 58、非共同KEEP 699、已知问题1。两处“2165”和“2203”对应不同日期、不同定义，不能互换。

本次重新计算确认：1663条均满足共同KEEP条件；1580/83的sample_id唯一、不交叉，逐条原文与父集合一致；选中与排除记录覆盖全部4908个候选行。冻结时的13份依赖文件（含新旧审核表）均仍存在且哈希吻合。这里复核已有审核证据，不新增或伪造人工复核人，也不要求重新进行一次全量人工审核。

远端实际派生train/validation JSONL与本地版本逐条内容和顺序相同，但JSON分隔空格不同，因此字节哈希不能直接互换。历史正式探索配置指向该派生目录，使用Qwen2.5-7B-Instruct原始基座。历史真实loader和790步探索训练属于历史技术证据，不等于本周loader通过，也不等于生成质量得到验证。

从1580条中另行按问题组做9:1划分，83条留在集合外。若不再剔除且分组允许精确取整，预期1422条train、158条validation，另有83条历史诊断。**这是预期，不是已生成结果**；实际数目由任务3的去重、评估隔离和完整分组确定。
