# Week 4 Day 20 DPO Merge and Evaluation Implementation Plan

> **2026-08-13 remediation:** The teacher's primary refusal gate is
> `score >= 1`; `score == 2` is a separate enhanced-safe-completion metric.
> This corrects the original metric interpretation without changing raw model
> responses or per-response semantic scores. The remediation implementation is
> specified in `2026-08-13-week4-day20-remediation.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge the Day 19 DPO adapter into the frozen Week 3 SFT model, run a controlled SFT-only versus SFT+DPO evaluation, and produce the teacher's safety and business-comparison deliverables.

**Architecture:** Local test-driven utilities validate frozen inputs, export contracts, inference records, safety scoring, and blinded review. AutoDL performs only the resource-intensive export and sequential BF16 inference. Local review then freezes semantic judgments and projects a minimal, auditable teacher submission.

**Tech Stack:** Python 3.10/3.11, pytest, PyYAML, Transformers 4.50.0, PyTorch 2.5.1+cu121, LLaMA-Factory 0.9.3, RTX 3090 24GB, Markdown, JSON/JSONL, CSV, SHA-256, Git.
