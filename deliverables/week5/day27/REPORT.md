## 4. 25 条图文推理结果

Day 23 使用 5 张图片 × 5 种问题形成 25 条固定矩阵，25/25 推理成功并完成人工复核。模型对明显自然场景、简单 OCR 和 UI 主体识别表现较好，对小字、精确数值、复杂公式以及严格格式约束较弱。两条记录达到固定 token 上限，在能力边界中作为失败模式保留。

## 5. 跨模态注意力方法与热力图

Day 24 固定使用第 20 层 self-attention，对目标文本 token 的前一个 causal prediction row 取视觉 token 权重，对 head 求均值并依据 merger 后的二维网格重排。实际交付 4 张热力图（要求至少 3 张），并保存 per-head、per-token 和 mean attention 数组。热力图只反映固定层与聚合规则下的关注分布，不等同于因果解释。

## 6. 十题视觉幻觉检测

Day 25 固定 10 题，10/10 有原始回答和二元审查；严格标注的幻觉数为 7，幻觉率为 `7/10=70%`。主要问题包括虚构小字、错读公式符号和在图中信息不足时仍给出确定断言。该比例是固定小样本的描述性结果，不外推到所有图像任务。

## 7. 数据与 VLM LoRA 训练

Day 26 首轮包含 200 条训练样本、20 条开发样本和 20 条最终样本，并完成图片 SHA 隔离、数据 schema 验证和训练血缘绑定。Day 27 从已审计的 200 条生成一组确定性改写，得到 400 条类别均衡纠偏数据，每类 80 条，与 v8 开发集无图片和 Prompt 交叉。

两个候选都冻结视觉塔与多模态 projector，只训练语言模型的 rank-16 LoRA：

- v8-E：从 v7-B adapter 续训，LR `2e-6`，`0.5` epoch，50 step，训练成功。
- v8-F：从 Base 重启，LR `1e-5`，`1.0` epoch，100 step，训练成功。

## 8. Base/LoRA 隔离盲评

开发门禁在看到结果前固定：均分增益 `>=0.35/5`、直接题增益 `>=0`、Base 未满分的机会题胜率 `>=50%`、幻觉率不更差。每个候选都使用同一 20 题和生成配置，在 A/B 身份揭盲前完成五维评分。

| 指标 | v8-E | v8-F | 门禁 |
|---|---:|---:|---:|
| Base 均分 | 3.9775 | 3.9775 | - |
| LoRA 均分 | 3.4075 | 3.5250 | - |
| 均分增益 | -0.5700 | -0.4525 | >=0.3500 |
| 直接题增益 | -0.2600 | -0.0250 | >=0 |
| 机会题胜率 | 3/12=25.00% | 4/12=33.33% | >=50% |
| Base/LoRA 幻觉率 | 40% / 60% | 40% / 55% | LoRA <= Base |
| 结论 | FAIL | FAIL | 四项全部通过 |

按预注册停止规则，两个开发集候选失败后不再开第三组，不采集新最终集，也不运行最终测试。

## 10. 失败、限制与后续改进

失败不是 GPU 更换或文件不同步导致：本轮数据、Base revision、父 adapter、新 adapter、生成配置与每次 run spec 都有 SHA-256 绑定。结果更符合小数据 LoRA 对输出风格和错误模式的放大：图表类有局部增益，但公式、UI、OCR 和指令约束整体退化。后续应增加真实人工核对的高质量样本，减少同图改写占比，先在小模型或离线教师评分上验证数据收益，再进行新 GPU 训练。

由于没有候选通过验收，不宣称存在“最终通过模型”。归档保留了历史开发结果最好的 v7-B Base+adapter 血缘，仅用于复现和后续迭代；它的开发集增益为 `+0.2425`，但直接题增益为 `-0.135`，仍未通过。详细路径、Base revision、adapter SHA、数据/配置 SHA 和加载证据见 `source/results/final_vlm_model_manifest.json`。
