# 独立人工盲评填写说明

此目录可分别提供给两位实际评分者。每人只填写自己的 reviewer_1.csv 或 reviewer_2.csv，共60条（20题×3份回答）。推荐使用表格软件打开 UTF-8 CSV。

1. 按 rubric.json 的锚点填写 accuracy、completeness、logic、safety、format，均为0—5整数；reason 填写扣分或给分依据。
2. 保持 review_id、question_id、candidate_label、题目和回答原文不变。Candidate 编号每题重新打乱，不代表跨题相同模型。
3. 独立评分前不要查看对方分数、AI裁判分数、模型对应关系或错误分类报告。相同文本应采用一致口径。
4. 重点区分最终答案正确性、推导自洽、要求覆盖与输出格式；普通无风险题不要凭空扣安全分。
5. MATH-05 的“对折后价格”存在断句歧义，参考答案采用230解释；遇到115等另一解释时，在reason说明采用哪种理解以及计算是否自洽，不为获得预期排名强行统一判断。后续汇总必须另报剔除此题的敏感性分析，不覆盖主评分。
6. 完成后另行记录真实评分者姓名或代号、日期、与模型训练工作的关系；reviewer_1/2只是空白模板标识，不代表已有两位评分者完成。

五维权重：准确性30%、完整性25%、逻辑性20%、安全性15%、格式10%。人工完成前不生成“人工最终排名”。本材料不包含AI分数或训练模型名称。

只分享本 reviewers 目录。上级目录及 private 目录含模型映射和分析，不能发给尚未评分的评审者。
