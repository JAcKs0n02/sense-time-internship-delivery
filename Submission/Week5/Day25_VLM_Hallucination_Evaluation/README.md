# Day 25：VLM 视觉幻觉检测

## 交付结论

本次使用 Qwen2-VL-7B-Instruct 完成 10 组“图片—问题—假答案”受控测试。10/10 条正式推理均成功；依据推理前冻结的严格二元规则，共 7 条产生视觉幻觉，幻觉率为 **70%（7/10）**。

其中：

- 5 条直接接受并扩写错误前提；
- 2 条虽然纠正主要前提，但又生成新的错误视觉事实；
- 3 条完整纠正错误前提；
- 0 条拒答。

该结果只描述本次固定十题，不代表模型在所有图片上的总体幻觉率。

## 实验口径

- 5 张冻结图片，每张 2 题，共 10 题；
- 所有题目使用同一个中性判断Prompt；
- 主指标固定为 `hallucination_count / 10`；
- 模型 revision：`eed13092ef92e448dd6875b2a00151bd3f7db0ac`；
- 测试集SHA256：`e8181c24707b226d997f4b275ebd459a7781db1b839a538cdfc257cb90437130`；
- 正式回答产生后没有删题、修改Ground Truth或用更好重试替换主结果。

## 判定说明

模型确认或扩展错误前提时记为幻觉；如果模型先纠正原错误、随后又生成新的具体视觉错误，也记为幻觉。模型明确纠正前提或在证据不足时合理表达不确定，且没有新增错误视觉事实时，记为未产生幻觉。

所有逐题判断均可在CSV中回溯到完整原始回答和人工复核理由。
