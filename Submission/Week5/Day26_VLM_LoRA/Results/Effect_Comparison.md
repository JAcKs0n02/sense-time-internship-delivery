# Day 26 Base 与 LoRA 效果对比

## 最终结论

v6 纠偏候选已完成独立最终盲评，但没有通过预注册的三项联合质量门槛。

| 指标 | Base | LoRA | 门槛 | 结果 |
|---|---:|---:|---:|---|
| 20 题加权均分 | 3.7825 | 3.7950 | LoRA 至少 +0.50 | FAIL（+0.0125） |
| 逐题胜出 | — | 12/20 | 至少 12/20 | PASS |
| 视觉幻觉率 | 65% | 55% | LoRA 不高于 Base | PASS |

总结果为 **FAIL**，因为三项条件要求同时成立。首轮 v2 最终评测同样保留：Base 3.9175、LoRA 3.8750、LoRA 8/20 胜、幻觉率 65%→45%，总结果 FAIL。

## 确认得到的改进

- LoRA 更稳定地使用“结论—可见依据”格式完成纠错指令；
- 在 CRUncover 表格纠错、火箭纠错、多图拼接纠错、购物收据 OCR、Word 界面和股票页面等样例上优于 Base；
- 最终集幻觉率下降 10 个百分点，说明 grounded 训练方向有效；
- LoRA 达到 12/20 胜，相比 v2 的 8/20 有实质改进。

## 仍然存在的问题

- 两道手写公式仍把模平方或求和下限识别错误；
- 多图 OCR 直答出现同一价格重复二十余次的严重退化；
- 对结构复杂的学术页面仍会把文档和图组误称为表格；
- 少数自然场景直答为追求简洁而漏掉关键主体名；
- OCR-14 纠错题的参考断言本身存在争议：图片基本是英文印刷收据。该题未因结果不利而删除，两个模型都按原冻结题评分。

## 为什么不能写成“明显提升”

训练 loss 下降、adapter 可加载、trainer/参数审计显示视觉塔冻结，只能证明工程训练成功，不能证明回答质量显著提升。纠偏候选虽然胜题数和幻觉率更好，但被公式和多图 OCR 的大幅失分抵消，均分只增加 0.0125。故提交材料使用“训练完成、效果验收未通过”的准确表述。

## 评测边界

- 最终图片与训练图片 SHA 零重叠，最终目标答案与训练目标答案精确重叠为 0；但同类任务沿用通用 Prompt 模板，因此结论只覆盖新图片上的受控任务泛化。
- v2 与 v6 是两次独立模型加载与推理。尽管最终 case/config 控制一致，13/20 条 Base 文本并非逐字相同，原因未被本轮证据完全隔离；因此只比较每次运行内部的 Base/LoRA 配对结果，不把 `3.9175→3.7825` 当作跨 run 的模型变化。
- v6 运行摘要最初只记录 adapter config 哈希；收尾时根据远端选定权重、adapter manifest 和 Day22 已验证基座 manifest，补做 adapter 权重与完整基座身份的运行后追溯绑定。后续脚本已改为推理前逐文件校验基座、校验 adapter 权重，并将基座/adapter/配置/样本/scale 写入不可变 run spec。

## 后续建议

Day 27 若继续优化，应在训练集与开发集上增加高质量公式转写和多图 OCR 目标，修正争议参考题，并新建从未用于本轮选模的最终集；不能继续对当前冻结最终集调参。
