# Day 26 LoRA 候选选择与纠偏记录

## 选择原则

所有候选都使用同一 Qwen2-VL-7B-Instruct 基座、冻结视觉塔和多模态投影层，只在语言模型线性层训练 LoRA。开发集固定为 20 条、10 张未进入训练的图片；最终集另有 20 条，在完成开发集选模前不用于调参。

候选选择优先级为：视觉事实正确性、指令完成度、完整性、实用性、格式，以及视觉幻觉是否减少。开发集只用于选模；是否达到“明显提升”仍由独立最终盲评决定。

## 候选轨迹

| 候选 | 关键设置 | 训练结果 | 开发集观察 | 决策 |
|---|---|---|---|---|

| v2 | rank 16，LR 2e-5，1 epoch，原始 200 条 | 50/50 steps，train loss 2.5223，eval loss 2.067574 | 开发集较 v1 稳定，估计均分 +0.325，约 10/20 胜 | 进入首轮最终盲评 |
| v3 | 仅 q/v，rank 8，LR 2e-5，1 epoch | 50/50 steps，train loss 2.7359，eval loss 2.3450 | 输出几乎回到 Base，改进不足 | 淘汰：容量不足 |
| v4 | 全 7 线性层，rank 8，LR 2e-5，2 epoch | 100/100 steps，train loss 2.3648，eval loss 1.8924 | 流程图/OCR/纠错改善，公式、自然场景和 UI 直答退化 | 淘汰：类别不平衡 |

| v6 | grounded 目标，主任务加权为 300 次采样；rank 16，LR 2e-5，1.5 epoch | 113/113 steps，train loss 2.1883，best checkpoint-84 | 纠错、场景、OCR、UI 明显改善；完整强度的公式较弱 | 继续搜索推理强度 |
| v6 × 0.75 | checkpoint-84，LoRA scale 0.75 | 不重训 | 公式恢复，但流程图直答重新出现指标幻觉；接近门槛 | 保留但不选 |

`LoRA scale` 只缩放已训练 adapter 的增量，不改变基座权重、数据、解码参数或测试题。0.75/0.85 的比较只发生在开发集，因此没有用最终集挑参数。

## 首轮最终盲评为何失败

v2 首轮最终盲评完整保留，未覆盖或删除：

- Base 均分：3.9175；
- LoRA 均分：3.8750；
- 均分增量：-0.0425；
- LoRA 胜出：8/20；
- Base / LoRA 幻觉率：65% / 45%；
- 结论：幻觉率改善，但均分和胜题数未达到预注册门槛，结果为 FAIL。

正式训练数据在各 run 中哈希一致，远端开发集一度存在两条旧参考标注，但训练 200 条未受影响；同步修正后重新跑开发集，并未改动冻结最终题。不过，v2 与 v6 两次独立推理的 Base 文本有 13/20 条不完全相同，现有证据无法把原因唯一归于 GPU、运行时或数值非确定性。因此跨 run 的 Base 均分不用于证明改善，只采用各 run 内部的配对比较。

## 纠偏策略

v6 没有用最终集答案反向构造训练数据。纠偏只包括：

1. 将同一 200 条人工复核事实改写为“可见事实—证据—不确定性边界”的 grounded 目标；
2. 对直答和纠错两类主任务做确定性加权采样，总训练采样 300 条，但教师数据集仍是 200 条唯一图文指令；
3. 使用开发集选择 checkpoint-84 与 LoRA scale 0.85；
4. 对同一冻结最终集重新随机盲化，明确标记为纠偏复测；
5. 评分前只读取匿名 A/B packet，冻结评分文件哈希后才读取私有映射；匿名材料、盲化参数和映射均不进入教师投影。

最终纠偏盲评结果为：Base 3.7825、LoRA 3.7950、均分增量 +0.0125、LoRA 12/20 胜、幻觉率 65%→55%。胜题数和幻觉率通过，但均分增量未达到 +0.50，因此联合门槛仍为 FAIL。原始 v2 失败结果始终作为审计记录保留。
